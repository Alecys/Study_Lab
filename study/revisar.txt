Não confunda:

HTTP = protocolo
REST = arquitetura/estilo
fetch = API JavaScript
SOP = SAME // política de segurança do navegador (não permite)
CORS = CROSS // mecanismo/política de acesso entre origins (permite)


São peças diferentes:

Coisa	O que é
HTTP	Protocolo de comunicação
HTTPS	HTTP protegido por TLS
Fetch	API JS para fazer requisições
REST	Estilo para projetar APIs
Origin	protocolo + host + porta
SOP	Política de segurança do navegador
CORS	Mecanismo para permitir acesso cross-origin

  API é a interface; REST é uma forma de projetar uma API web; HTTP é o protocolo que transporta a comunicação; GET/POST/DELETE são métodos do HTTP; JSON é um formato de dados; e fetch() é uma ferramenta JavaScript para fazer as requisições.
