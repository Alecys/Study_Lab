NODE.JS

Node.js

Aqui começa a ficar interessante.

Você precisa entender:

Node.js
   ↓
npm
   ↓
package.json
   ↓
node_modules
   ↓
scripts
   ↓
dependências

Por exemplo:

npm init

depois:

npm install

e entender:

{
  "scripts": {
    "dev": "...",
    "build": "...",
    "test": "..."
  }
}

-------------------------------
GIT
Não apenas:

git add .
git commit
git push

Mas entender o fluxo:

Working Directory
       ↓
git add
       ↓
Staging Area
       ↓
git commit
       ↓
Local Repository
       ↓
git push
       ↓
GitLab/GitHub

E depois:

branch
   ↓
feature
   ↓
commit
   ↓
push
   ↓
merge request / pull request
